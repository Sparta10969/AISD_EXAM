Суть: Ключи всегда отсортированы (k1<k2<⋯<kn)

Операции 

    Поиск:
        Бинарный поиск (деление отрезка пополам).
        Сложность: Θ(log⁡2 n)
    Вставка:
        Найти позицию вставки (чтобы не нарушить порядок).
        Сдвинуть все элементы правее позиции на 1 вправо.
        Вставить элемент.
        Сложность: Θ(n).
    Удаление:
        Найти элемент (бинарный поиск).
        Сдвинуть все элементы правее на 1 влево, закрывая «дыру».
        Сложность: Θ(n).

## Билет 14: Хеш-таблицы с открытой адресацией
Суть: Все элементы хранятся непосредственно в ячейках массива таблицы. Списков нет.

Основные понятия 

    Последовательность исследований: h(k,0),h(k,1),
    h(k,0),h(k,1),— это перестановка индексов 0..m−1

    Статусы ячеек или поле busy
        FREE (0) — ячейка никогда не использовалась.
        OCCUPIED (1) — ячейка занята.
        DELETED (2) — ячейка была занята, но элемент удален.

Особенности 

    Поиск: останавливается при встрече FREE. DELETED пропускает.

    Вставка: может использовать ячейки со статусом DELETED или FREE. Лучще запоминать обе, потому что при поиске мы обязаны дойти до конца и их сравнивать, чтобы вставить в ближайшую (Овчаренко подшар)

    Удаление: нельзя ставить статус FREE (это разорвет цепочку пробирования для других элементов). Ставится статус DELETED.

## Билет 16: Хеш-таблица: квадратичное исследование, двойное хеширование. Оценка эффективности.

1. Квадратичное исследование (Quadratic Probing)

Это метод разрешения коллизий в открытой адресации, при котором расстояние между следующими проверяемыми ячейками растет квадратично.
Хеш-функция:
```
h(k,i)=(h′(k)+c1⋅i+c2⋅i^2)(mod m)

    k — ключ.
    i — номер исследования (пробирования), i=0,1,2, ...

    h′(k) — вспомогательная хеш-функция (базовая позиция).

    m — размер таблицы.

    c1​,c2​ — вспомогательные константы c1,c2≠0
```

Особенности:

    Позволяет избежать первичной кластеризации (когда блоки занятых ячеек сливаются в длинные цепочки, как при линейном пробировании).
    Ограничения: Для того чтобы последовательность проб была перестановкой 0,…,m−1  (т.е. чтобы алгоритм гарантированно нашел свободное место, если оно есть), требуется выбор специальных значений c1,c2 и m
    m выбирают простым числом, а константы так, чтобы покрыть хотя бы половину таблицы.

2. Двойное хеширование (Double Hashing)

Один из лучших методов открытой адресации. Использует две хеш-функции.
Хеш-функция:
```
h(k,i)=(h1(k)+i⋅h2(k))(modm)

    h1​(k) — основная хеш-функция (определяет начальную позицию).
    h2​(k) — вторая хеш-функция (определяет шаг смещения).
    i — номер попытки.
```

Ключевые требования:

    Значение h2(k)
    h2​(k) должно быть взаимно простым с размером таблицы m.
        Вариант реализации: 
        m — простое число, а h2(k)
        h2​(k) возвращает натуральные числа, меньшие m (например, 1≤h2(k)<m1.
    Это гарантирует, что последовательность исследования будет перестановкой всех индексов таблицы 0,…,m−11

Преимущество:

    Минимизирует как первичную, так и вторичную кластеризацию. Элементы с разными ключами будут "прыгать" по таблице с совершенно разными шагами.

3. Оценка эффективности

Эффективность хеш-таблиц с открытой адресацией зависит от коэффициента заполнения:
```
σ=n/m
```
где
n — количество элементов,
m — размер массива.
Предполагается равномерное хеширование (все элементы отображаются на ячейки независимо и равновероятно).
